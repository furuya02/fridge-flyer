

### 料理1: 豚バラとキャベツのとろとろミルク煮

**紹介**: 冷蔵庫のキャベツと牛乳をたっぷり使った、体が温まるやさしい味わいの煮込み料理です。特売の豚バラ肉を加えることで旨味とコクが格段にアップします。

**材料**:
- 豚バラ肉うす切り … 200g
- キャベツ … 1/4玉（ざく切り）
- 玉ねぎ … 1個（くし切り）
- 牛乳 … 200ml
- 水 … 200ml
- 塩 … 小さじ1
- こしょう … 少々
- コンソメ（家庭の常備調味料） … 1個
- バター（あれば） … 10g

**レシピ**:
1. 豚バラ肉を食べやすい大きさに切り、フライパンで中火で炒めて軽く焼き色をつける
2. 玉ねぎを加えてしんなりするまで炒め、キャベツも加えてさっと炒め合わせる
3. 水とコンソメを加え、蓋をして中火で10分ほど煮込み、キャベツが柔らかくなるまで加熱する
4. 牛乳を加えて弱火にし、沸騰させないように5分ほど煮込む
5. 塩・こしょうで味を調え、あればバターを落として完成

**買い物リスト**:
- 北海道産 豚バラ肉うす切り 300g … 498円

### 料理2: ハムと彩り野菜のオープンサンド 粉チーズがけ

**紹介**: 冷蔵庫のパン・ハム・トマト・パプリカを全て活かした、彩り鮮やかなオープンサンドです。特売の粉チーズを振りかけてトースターで焼き上げれば、カフェ風の一品に仕上がります。

**材料**:
- 食パン … 2枚
- スライスハム … 4枚
- トマト … 1個（薄切り）
- 黄パプリカ … 1/2個（薄切り）
- キャベツ … 2〜3枚（千切り）
- 粉チーズ … 大さじ2〜3
- マヨネーズ（家庭の常備調味料） … 適量
- 塩・こしょう … 少々

**レシピ**:
1. キャベツを千切りにし、塩少々を振って軽く揉み、水気を絞っておく
2. トマトは5mm程度の薄切りに、黄パプリカは細切りにする
3. 食パンにマヨネーズを薄く塗り、千切りキャベツ→ハム→トマト→黄パプリカの順に重ねてのせる
4. 粉チーズをたっぷり振りかけ、オーブントースターで4〜5分、チーズに軽く焼き色がつくまで焼く
5. お好みでこしょうを振って完成

**買い物リスト**:
- 雪印メグミルク 粉チーズ マイルド 50g … 258円

### デザート: 王林りんごのミルクコンポート

**紹介**: 特売の王林りんごを牛乳でじっくり煮込んだ、やさしい甘さのホットデザートです。りんごの芳醇な香りとミルクのまろやかさが溶け合い、砂糖控えめでも十分な満足感があります。

**材料**:
- 王林りんご … 2玉
- 牛乳 … 200ml
- 砂糖（家庭の常備調味料） … 大さじ3
- バニラエッセンス（あれば） … 少々
- シナモン（あれば） … 少々

**レシピ**:
1. りんごは皮をむいて8等分のくし切りにし、芯を取り除く
2. 鍋にりんご・砂糖・牛乳を入れ、弱火にかける
3. 沸騰させないように注意しながら、蓋をして弱火で15〜20分、りんごが透き通って柔らかくなるまでじっくり煮る
4. お好みでバニラエッセンスやシナモンを加え、軽く混ぜる
5. 器に盛り、温かいままでも冷蔵庫で冷やしても美味しくいただける

**買い物リスト**:
- 青森県産 王林りんご（糖度13度）5玉 … 498円
