# 冷蔵庫の食材を活かした3つのレシピ提案

---

### 料理1: BLTオープンサンド 〜彩り野菜たっぷり〜

**紹介**: 冷蔵庫にあるパン・ハム/ベーコン・トマトを主役に、チラシ特売のサニーレタスを加えた、朝食にもランチにもぴったりの華やかなオープンサンドです。黄パプリカの彩りが食卓を春らしく演出します。

**材料**:
- パン（食パンまたはロールパン）… 2〜4枚
- ハム／ベーコン（スライス）… 4〜6枚
- トマト … 1個（スライス）
- 黄パプリカ … 1/2個（薄切り）
- サニーレタス … 2〜3枚 **【買い足し】**
- マヨネーズ・塩・こしょう・バター … 各適量（家庭の常備調味料）

**レシピ**:
1. パンをトースターで軽くこんがり焼き、片面にバターを薄く塗る。
2. ハム／ベーコンをフライパンで中火でカリッと焼く（ベーコンの場合は油不要、ハムの場合はバター少々で）。
3. トマトは5mm厚の輪切りに、黄パプリカは薄くスライスする。
4. サニーレタスは洗って水気をしっかり切り、食べやすい大きさにちぎる。
5. トーストの上にサニーレタス → マヨネーズを細く絞る → トマト → 焼いたハム/ベーコン → 黄パプリカの順に重ねる。
6. 仕上げに塩・こしょうを軽く振り、お好みでマヨネーズを追加して完成。

**買い物リスト**:
- サニーレタス（福岡県産他）… 1個／128円（税抜）

### 料理2: 野菜たっぷりタコス 〜トルティーヤで巻く春ごはん〜

**紹介**: チラシで特売中のトルティーヤを買い足し、冷蔵庫のキャベツ・玉ねぎ・トマト・黄パプリカをたっぷり使ったカラフルなタコス風ラップです。ハムを具材のたんぱく質として活用し、手軽なのに満足感のある一品に仕上げます。

**材料**:
- トルティーヤ（プレーン）BESTPRICE **【買い足し】**
- キャベツ … 1/4玉（千切り）
- 玉ねぎ … 1個（半分はみじん切り、半分はスライス）
- トマト … 残り半分〜1個（角切り）※料理1と分けて使用
- 黄パプリカ … 残り1/2個（角切り）
- ハム／ベーコン（スライス）… 3〜4枚（細切り）
- サニーレタス … 残り（料理1の余り）
- 【サルサソース】トマト角切り＋玉ねぎみじん切り＋塩＋レモン汁（またはお酢）＋少量のごま油かオリーブオイル
- 塩・こしょう・お好みでケチャップやマヨネーズ

**レシピ**:
1. **即席サルサを作る**：トマト1/4個分を細かい角切り、玉ねぎ1/4個分をみじん切りにし、ボウルで塩ひとつまみ・酢（またはレモン汁）小さじ1・オリーブオイル小さじ1と和えて冷蔵庫で休ませる。
2. キャベツを千切りにし、水にさらしてシャキッとさせ、水気を切る。
3. 黄パプリカは1cm角の角切り、玉ねぎ（残り）は薄くスライスする。
4. フライパンに少量の油を熱し、スライスした玉ねぎ → ハム/ベーコン細切り → 黄パプリカの順に中火で2〜3分炒め、塩・こしょうで味を調える。
5. トルティーヤをフライパンまたは電子レンジで軽く温める（しなやかになり巻きやすくなる）。
6. 温めたトルティーヤの中央にサニーレタス → キャベツ千切り → 炒めた具材 → 即席サルサソースの順にのせる。
7. お好みでケチャップやマヨネーズをかけ、両端を折り込みながらくるりと巻いて完成。

**買い物リスト**:
- トルティーヤ（プレーン）BESTPRICE … 1袋／398円（税抜）

### デザート: パインブロックのミルクプリン 〜ふるふる春スイーツ〜

**紹介**: チラシ特売のパインブロックと冷蔵庫の牛乳を組み合わせた、やさしい甘さのミルクプリンです。ゼラチンなしでも片栗粉で作れる簡単バージョンもご紹介。ゴロッとしたパインの食感と、なめらかなミルクプリンのコントラストが楽しい春のデザートです。

**材料**:
- 牛乳（おいしい牛乳）… 200ml
- パインブロック（キャジディーナ デラックス） **【買い足し】** … 1/2パック分（残りは翌日のおやつに）
- 砂糖 … 大さじ2〜3（お好みで調整）
- 片栗粉 … 大さじ1と1/2（ゼラチンがあればゼラチン5gでも可）
- 水 … 大さじ2（片栗粉を溶く用）
- バニラエッセンス … あれば2〜3滴

**レシピ**:
1. パインブロックの半量を1cm角の小さめに切り、グラスやカップの底に均等に入れておく。残りの半量は飾り用に少し大きめに切っておく。
2. 小鍋に牛乳と砂糖を入れ、弱〜中火で温めながら砂糖を完全に溶かす（沸騰させない）。
3. **片栗粉バージョン**：水で溶いた片栗粉を②に少しずつ加え、とろみがつくまで絶えず混ぜながら2〜3分加熱する。/**ゼラチンバージョン**：火を止めてからふやかしたゼラチンを加え、よく混ぜて溶かす。
4. お好みでバニラエッセンスを加えてひと混ぜする。
5. パインを入れたグラスに③を静かに注ぎ入れ、粗熱が取れたらラップをして冷蔵庫で2〜3時間冷やし固める。
6. 食べる直前に飾り用のパインブロックをトップにのせて完成。お好みで牛乳を少量かけても美味。

**買い物リスト**:
- キャジディーナ デラックス パインブロック … 1パック／398円（税抜）
