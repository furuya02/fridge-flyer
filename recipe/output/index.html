作り方を見る
  1. パンをトースターで軽くこんがり焼き、片面にバターを薄く塗る。
  2. ハム／ベーコンをフライパンで中火でカリッと焼く（ベーコンの場合は油不要、ハムの場合はバター少々で）。
  3. トマトは5mm厚の輪切りに、黄パプリカは薄くスライスする。
  4. サニーレタスは洗って水気をしっかり切り、食べやすい大きさにちぎる。
  5. トーストの上にサニーレタス → マヨネーズを細く絞る → トマト → 焼いたハム/ベーコン → 黄パプリカの順に重ねる。
  6. 仕上げに塩・こしょうを軽く振り、お好みでマヨネーズを追加して完成。
  7. **即席サルサを作る**：トマト1/4個分を細かい角切り、玉ねぎ1/4個分をみじん切りにし、ボウルで塩ひとつまみ・酢（またはレモン汁）小さじ1・オリーブオイル小さじ1と和えて冷蔵庫で休ませる。
  8. キャベツを千切りにし、水にさらしてシャキッとさせ、水気を切る。
  9. 黄パプリカは1cm角の角切り、玉ねぎ（残り）は薄くスライスする。
  10. フライパンに少量の油を熱し、スライスした玉ねぎ → ハム/ベーコン細切り → 黄パプリカの順に中火で2〜3分炒め、塩・こしょうで味を調える。
  11. トルティーヤをフライパンまたは電子レンジで軽く温める（しなやかになり巻きやすくなる）。
  12. 温めたトルティーヤの中央にサニーレタス → キャベツ千切り → 炒めた具材 → 即席サルサソースの順にのせる。
  13. お好みでケチャップやマヨネーズをかけ、両端を折り込みながらくるりと巻いて完成。
  14. パインブロックの半量を1cm角の小さめに切り、グラスやカップの底に均等に入れておく。残りの半量は飾り用に少し大きめに切っておく。
  15. 小鍋に牛乳と砂糖を入れ、弱〜中火で温めながら砂糖を完全に溶かす（沸騰させない）。
  16. **片栗粉バージョン**：水で溶いた片栗粉を②に少しずつ加え、とろみがつくまで絶えず混ぜながら2〜3分加熱する。/**ゼラチンバージョン**：火を止めてからふやかしたゼラチンを加え、よく混ぜて溶かす。
  17. お好みでバニラエッセンスを加えてひと混ぜする。
  18. パインを入れたグラスに③を静かに注ぎ入れ、粗熱が取れたらラップをして冷蔵庫で2〜3時間冷やし固める。
  19. 食べる直前に飾り用のパインブロックをトップにのせて完成。お好みで牛乳を少量かけても美味。
